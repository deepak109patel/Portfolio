# Deepak Kumar Patel — Portfolio

A modern, dark-themed personal portfolio website built with HTML, CSS, and vanilla JavaScript.

## 🔗 Live Site
Coming soon via GitHub Pages

## ✨ Features
- Responsive dark-mode design with glassmorphism elements
- Animated hero section with floating particles
- Scroll-reveal animations
- Interactive skill proficiency bars
- Project showcase with GitHub links
- Competitive programming achievements
- Contact form with mailto integration

## 🛠️ Tech Stack
`HTML5` · `CSS3` · `Vanilla JavaScript`
